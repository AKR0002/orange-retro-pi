# Orange Pi 4A Retro Handheld 

## About the project

I'm making my own retro gaming handheld using the Orange Pi 4A (2GB RAM).

The idea is to make a portable gaming console that has a similar layout to a Nintendo Switch Lite, but with my own design and button layout.

I wanted to make something that combines hardware, electronics and CAD modelling instead of just making another software project.

## What I'm using

- Orange Pi 4A (2GB RAM)
- LCD display
- Battery
- Cooling fan
- CPU heatsink
- D-pad
- ABXY buttons
- Two analogue sticks
- L1 and R1 shoulder buttons
- L2 and R2 rear triggers
- Speakers
- USB-C charging port

## Design

I'm using Onshape to design the handheld and work out where all the components will go.

The design includes:
- A front and back casing
- Screen placement
- Button layout
- Analogue sticks
- Rear triggers
- Internal motherboard and cooling layout

The CAD model is still being worked on, so some of the parts are currently placeholders.

## Current progress

I've started modelling the individual components in Onshape and have moved on to putting them together in an assembly.
